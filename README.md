# DepMap WRN 26Q3

Reproducibility and extension study of WRN dependency in
microsatellite-instable cancer models using DepMap 26Q3 data
and public CCLE whole-genome sequencing.

## Current research question

Can the broken-(TA)n repeat phenotype associated with WRN
dependency be reconstructed from current public WGS data, and
does it explain variation in WRN dependency among MSI models
better than conventional MSI measurements?

## Status

Active exploratory research.

Current checkpoint:
- Published broken-TA / WRN association reproduced.
- Generic microsatellite repeat burden did not robustly explain
  WRN dependency beyond MSI.
- 5,377 of 5,400 published broken-TA loci successfully lifted
  from hg19 to hg38.
- Public hg38 WGS is available for all 26 MSI models in the
  current comparison cohort.
- Current-WGS reconstruction is being validated first in KM12
  (ACH-000969).
