# Current-WGS Results

This directory contains the tracked outputs supporting the final 26-model
current-WGS analysis.

## Per-model reconstruction

Each `ACH-*` directory contains a tracked `result.json` summarizing that
model's reconstruction, including FPBM values and available provenance.

Large locus-level coverage files (`*.bedcov.tsv`) are intentionally excluded
from Git. They can be regenerated by the canonical extractor.

Most models were reconstructed using the final result schema. HCT116
(`ACH-000971`) and SK-MEL-2 (`ACH-001190`) were completed during earlier
extractor revisions and retain older result schemas. Their underlying
reconstruction results are preserved rather than rewritten after the fact.

## Cohort summary

`cohort_summary.csv` combines the 26 per-model reconstructions and records
status, published/current FPBM values, ratios, execution metadata, checksums,
result schema, and extractor commit where available.

## Final analyses

- `reconstruction_analysis.txt`
- `reconstruction_diagnostics.csv`

Published FPBM versus independently reconstructed current-WGS FPBM.

- `wrn_association_analysis.txt`
- `wrn_association_diagnostics.csv`

Reconstructed FPBM versus current WRN GeneEffect.

- `beyond_msi_analysis.txt`
- `beyond_msi_diagnostics.csv`

Canonical MSI-adjusted association analysis.

- `beyond_msi_robustness.txt`
- `beyond_msi_leave_one_out.csv`

Leave-one-out and bootstrap sensitivity analysis.

- `loocv_prediction_analysis.txt`
- `loocv_predictions.csv`

Out-of-sample comparison of MSI-only and MSI-plus-FPBM models.

- `calibration_audit.txt`
- `calibration_audit.csv`

Scale-shift characterization and JHUEM-1 discrepancy audit.

## Figures

Presentation figures derived from these outputs are under:

```text
figures/current-wgs/
```

They are regenerated by:

```bash
python3 scripts/make_current_wgs_figures.py
```

Both PNG and SVG outputs are deterministic under the recorded closeout
environment.
